# Ястреб v0.1.2

Исправлено прерывание поиска ответа при переключении диалогов. Принятый запрос
выполняется в фоне, ответ с источниками сохраняется в исходном диалоге.
В истории отображается индикатор работы; при завершении страница обновляется
автоматически. Повторный запрос в занятом диалоге блокируется, другие диалоги
остаются доступны.

Удаление диалога во время генерации не восстанавливает его после завершения.
Ошибка модели записывается в исходную переписку. Чужие задания и ответы недоступны.

## Обновление Windows / Astra Linux

1. Дождитесь завершения текущих запросов и остановите приложение.
2. Сохраните резервную копию каталога `data`.
3. Распакуйте исходный архив поверх каталога приложения, включая новые
   `yastreb/jobs.py` и `yastreb/runtime.py`. Не заменяйте `data`, `models` и `.venv`.
4. Запустите `start.cmd` (Windows) или `bash start-linux.sh` (Astra Linux).

Новых зависимостей нет. Переиндексация документов и миграция базы не требуются.
Исходный архив предназначен для обновления подготовленной установки. Он не содержит
Python, Ollama, модели и личные данные; для первой установки следуйте README.md.
Автономная установка на чистой Astra этим архивом не обеспечивается.

Очередь существует в памяти одного серверного процесса. Переключение диалога,
обновление страницы или закрытие браузера не отменяет запрос. Перезапуск сервера
прерывает незавершённые запросы; автоматическое восстановление после перезапуска
не входит в этот релиз. Запросы обрабатываются последовательно, до 32 в очереди.

## Проверка исправления

Запустите вопрос в первом диалоге, до завершения откройте второй, затем вернитесь
в первый. Во время работы должен быть виден статус ожидания, после завершения —
сохранённый ответ с источниками. Ответ не должен попадать во второй диалог.

Для новой установки на Astra Linux требуется проверка на целевой версии ОС.
Сборка и автоматические тесты этого исправления выполнены на Windows/Python 3.12.
