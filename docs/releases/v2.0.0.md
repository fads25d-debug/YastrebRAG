# Ястреб 2.0 — папки, Word и просмотр источников

Релиз 2.0.0 включает все доработки предыдущих версий: два режима поиска,
учётные записи и права загрузки, историю и удаление диалогов, настройки оформления
и фоновую генерацию, которая продолжается при переключении между диалогами.

В шестерёнке → «Внести изменения» появился выбор целой папки. PDF, DOCX и DOC из
вложенных папок добавляются в общую библиотеку, затем индексируются. Дубликаты
определяются по содержимому. Ошибки отдельных файлов отображаются в отчёте.

В блоке источника ответа появилась ссылка-кнопка «Открыть найденный фрагмент ↗».
PDF открывается на нужной странице с изображением оригинала и выделенным текстом;
Word — на нужном абзаце, включая абзацы в ячейках таблиц. Можно переходить к соседним
страницам/абзацам, скачать оригинал и вернуться к диалогу. Просмотр Word текстовый;
печатная нумерация страниц Word не используется.

## Обновление

1. Дождитесь завершения запросов и остановите приложение. Сохраните резервную копию `data`.
2. Обновите код, включая `yastreb/documents.py` и `yastreb/viewer.py`.
3. Установите зависимости: `.venv/Scripts/python.exe -m pip install -r requirements.txt`
   (Linux: `.venv/bin/python -m pip install -r requirements.txt`). Добавлен pypdfium2 5.12.1.
4. Для старых DOC установите LibreOffice на сервере. На Astra используйте разрешённый
   пакет `libreoffice-writer`. При необходимости задайте `YASTREB_LIBREOFFICE` — путь к soffice.
   DOCX не требует офисного пакета. Если LibreOffice отсутствует, DOC будет указан в отчёте ошибок.
5. Перезапустите приложение. Переиндексируйте старую библиотеку для новых точных ссылок.

Миграция пользователей не требуется. Старые PDF и история сохраняются. Снимки
извлечённого текста хранятся вместе с оригиналами в `data/library/documents`;
переносите каталог целиком. Импорт не следит за изменениями исходной папки автоматически:
повторите его вручную, если файлы изменились. Старые версии остаются доступными.

Ограничения: 1000 файлов / 500 МиБ за импорт, до 50 МиБ на документ; OCR отсутствует.
Макеты и сложные таблицы Word показываются как последовательность текстовых абзацев.
Пакет исходников не включает модели, Python и LibreOffice. На новой Astra необходимо
проверить запуск на фактической версии ОС.
