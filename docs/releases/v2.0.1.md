# Ястреб 2.0.1

Исправлен сбой автообновления интерфейса с ошибкой импорта `NDArray` из частично
инициализированного `numpy._typing`. Числовой интервал таймера исключает ненужный
импорт NumPy/pandas одновременно с загрузкой моделей фоновым обработчиком.
Добавлен регрессионный тест. Все возможности версии 2.0.0 сохранены.

## Обновление

Дождитесь завершения запросов, остановите приложение и сохраните резервную копию
`data`. Обновите исходники, не заменяя `data`, `models` и `.venv`, затем запустите
`start.cmd` на Windows или `bash start-linux.sh` на Linux.

При обновлении с 2.0.0 новые зависимости и переиндексация не требуются.
Архив содержит исходники, но не модели, Python или личные документы.
