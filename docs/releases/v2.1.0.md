# Ястреб 2.1.0 — автоматическая установка Windows

## Новая установка

Распакуйте архив в постоянную папку с правом записи и дважды нажмите `install.cmd`.
Скрипт самостоятельно подготовит Python 3.12, зависимости, Ollama и обе модели,
проверит импорт PDF, индексацию и реальный ответ, затем откроет форму создания
администратора: корпоративная почта, имя и пароль. Последующие запуски — `start.cmd`.

Нужны Windows 10/11 x64, Интернет на время первоначального скачивания, минимум
16 ГБ ОЗУ; рекомендуется 30 ГБ свободного места. Установка скачивает несколько
гигабайт и может занять длительное время. После установки Интернет не нужен.
Обязательной NVIDIA/CUDA нет: выбран совместимый CPU-режим.
Если отсутствует Microsoft Visual C++ Runtime, установится официальный подписанный
пакет Microsoft; Windows может запросить UAC или перезагрузку.

## Что исправлено

- Старый установщик ставил только библиотеки Python, не подготавливая модели.
- Ошибки внешних установочных команд теперь прекращают установку с журналом,
  а не приводят к ложному сообщению об успехе.
- Проверяется комплектность и загрузка эмбеддингов, а не только наличие папки.
- Служебные файлы загрузки больше не меняют отпечаток модели и не ломают индекс.
- Создание администратора больше не требует ручного задания параметров запуска.
- Добавлены проверки повторной установки, изоляции процесса Ollama и локального
  доступа к первичной настройке. Ollama Windows использует порт 11435.

## Обновление существующей установки

Дождитесь завершения запросов, остановите приложение, сохраните резервную копию
`data`. Обновите исходники, сохраняя `data`, `models` и `.venv`, и запустите `install.cmd`.
Пароли, документы и история сохраняются. Если отпечаток модели изменился, установщик
переиндексирует существующую библиотеку. Журнал: `data/logs/install-*.log`.

Старые DOC требуют отдельно установленного LibreOffice; PDF и DOCX работают без него.
OCR не добавлен. Релиз содержит исходники и онлайн-установщик, не готовый офлайн-образ.
Автоматическая установка этого релиза рассчитана на Windows; Astra-установщик
не переработан, проверка на Astra в этот релиз не входит.
