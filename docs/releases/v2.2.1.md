# Ястреб 2.2.1 — проверенный выпуск с презентациями и OCR

Включает все возможности 2.2.0:

- PPTX/PPT: текст слайдов, таблицы с контекстом заголовков и OCR надписей на рисунках.
- Ссылки на найденный слайд, просмотр через LibreOffice, скачивание оригинала.
- Локальное OCR сканированных PDF на русском и английском, прогресс и сохранённые предупреждения.
- Установка Tesseract через Windows-установщик с проверкой SHA256.

Исправлена проверка лимита распаковки PDF, которая ошибочно зависела от наличия
Tesseract на машине тестирования. Код приложения и формат данных относительно
2.2.0 не изменились. Теперь релиз публикуется только после успешных тестов GitHub
на Windows и Linux и содержит именно проверенный коммит.

## Установка

Полностью распакуйте архив и запустите **`install.cmd`**. Интернет нужен для
первой загрузки компонентов; затем программа работает автономно. При первом
запуске создайте администратора, последующие запуски — **`start.cmd`**.

Для старых **PPT/DOC** и визуального просмотра слайдов установите **LibreOffice**
отдельно. Импорт PPTX и текстовый просмотр работают без офисного пакета.
Рисунки распознаются только как текст: смысл схем не интерпретируется. SmartArt
и встроенные диаграммы отмечаются предупреждениями; для OCR нужна их растровая копия.

Для обновления остановите приложение, сделайте резервную копию `data`, обновите
исходники, сохраняя `data`, `models`, `tools` и `.venv`, затем запустите `install.cmd`.
Если уже установлена 2.2.0, переиндексация ради этой поправки не нужна.

Архив содержит исходники и онлайн-установщик, не модели и не пользовательские
данные. Реальные OCR, импорт/просмотр PPT/PPTX и ответы локальных моделей проверены
на Windows. Тесты на Ubuntu не заменяют установку на Astra Linux: она не проверялась.
