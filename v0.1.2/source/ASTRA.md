# Перенос «Ястреба» на Astra Linux

## Статус комплекта

Цель: Astra Linux 1.7/1.8 **x86-64**, CPU, Python 3.12.
В комплекте исходники, веса BGE-M3 и Qwen, согласованный снимок базы
учётных записей и истории, исходные PDF рабочей библиотеки (если добавлены).
Windows Python, Windows Ollama, демонстрационные данные и тестовые документы
не включены. Индексы пересоздаются после переноса.

Это комплект с **первоначальной установкой через Интернет**, не полностью
автономный установочный образ: Linux Python, пакеты и Ollama скачиваются
на целевой машине. На настоящей Astra этот комплект пока не испытан.
Точный выпуск ОС, ядро, политика безопасности и доступность пакетов могут
потребовать настройки администратором. Защитные механизмы Astra не отключайте.

## Установка

1. Перенесите всю папку с рабочего стола на Linux, например в `~/yastreb`.
   Нужна файловая система с поддержкой файлов более 4 ГБ: **не FAT32**.
   На целевом диске предусмотрите не менее 25 ГБ свободного места, 16 ГБ ОЗУ.
2. Откройте терминал в перенесённой папке. Все последующие команды — из неё.
3. Проверьте копию: `sha256sum --check --quiet SHA256SUMS`.
4. Через администратора установите системные инструменты из разрешённых
   репозиториев Astra:

   ```bash
   sudo apt-get update
   sudo apt-get install ca-certificates curl tar zstd libgomp1
   ```

5. **Без sudo**, под пользователем, который будет запускать приложение:

   ```bash
   bash install-astra.sh
   bash start-linux.sh
   ```

   Установщик скачивает локальный Python 3.12 через uv и Linux Ollama 0.34.0,
   проверяет SHA256 архива Ollama, устанавливает CPU PyTorch и зависимости.
   Системный Python не заменяется. Потребуется доступ к GitHub, PyPI,
   files.pythonhosted.org и download.pytorch.org. При ошибке установки
   остановитесь и сохраните вывод терминала; успешный запуск не гарантируется
   одним лишь наличием папки с программой.

6. Откройте **http://127.0.0.1:8502**. Вход по существующей почте и паролю.
   Пароль администратора не сбрасывается. Окно терминала оставьте открытым.
7. Если документы уже были в библиотеке: шестерёнка → «Внести изменения» →
   «Переиндексировать». Если библиотека пуста — добавьте рабочие PDF.
8. Отключите Интернет, перезапустите `bash start-linux.sh`, проверьте оба режима,
   цитаты и отказ на вопрос вне документов. Только после этой проверки
   принимайте автономную работу на конкретной Astra.

## Диагностика и безопасность

- `cat /etc/astra_version; uname -m; ldd --version` — сведения о системе.
- `data/logs/ollama.err.log` — журнал запуска модели.
- `.venv/bin/python -m scripts.check_environment` — проверка компонентов при запущенном Ollama.
- `.venv/bin/python -m scripts.smoke_rag` — сквозной тест с отдельной синтетической библиотекой.
- Если порт 11434 занят системным Ollama без перенесённой модели, согласуйте
  остановку этого сервиса с администратором. Скрипт чужие процессы не завершает.
- Скрипт завершает только собственный Ollama при завершении интерфейса.
- По умолчанию доступ только с этого компьютера. Для корпоративной сети
  нужен внутренний HTTPS reverse proxy; не публикуйте Ollama и Chroma.
- Комплект содержит персональную историю и хеши паролей: не размещайте его
  в общедоступной папке, выдайте права только владельцу/администратору.
- Не переносите заново старый снимок поверх работающей базы: потеряется новая история.
- На CPU ответы могут занимать минуту и больше. GPU настраивается отдельно.

Источники установки: [Python через uv](https://docs.astral.sh/uv/guides/install-python/),
[Linux Ollama](https://docs.ollama.com/linux).
