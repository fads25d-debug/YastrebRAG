# Выполнение плана «Ястреб»

## Уточнения от 15 сентября 2026

- Пользователь разрешил начать реализацию и добавил два режима: быстрый Top-3 и подробный Top-8.
- Backend имеет публичный контракт Backend(data_dir, embedding_path, ollama_url, model), методы ingest/rebuild/answer/status; код вынесен в yastreb/backend.py.
- Корпоративная почта используется как логин локальной учётной записи с паролем. Заголовки прокси без подтверждённой схемы доверия не принимаются. Интеграция AD остаётся отдельным этапом.
- История сохраняется в SQLite по владельцу, а не только в session_state. Сохранённые диалоги не смешиваются между пользователями.
- Ошибочные тестовые конструкции старого плана (несуществующий fixture PDF, fail_after в production, повторный тест can_manage вместо загрузки) заменяются поведенческими тестами реальных интерфейсов.
- Изолированное Python-окружение создано в .venv; исходный прототип остаётся в .superpowers.

## Итог реализации — 21 сентября 2026

- Рабочий Streamlit доступен на http://127.0.0.1:8502, health endpoint возвращает ok. Деморежим отключён.
- Учётная запись первого администратора уже создана пользователем; пароль не менялся.
- Установлены локальные Ollama 0.34.0, qwen2.5:7b Q4_K_M и BGE-M3. Архив Ollama проверен по официальной SHA-256 сумме.
- Реализованы быстрый Top-3 и подробный Top-8, персональная история SQLite, роли, подтверждение загрузки, настройки вверх внутри sidebar.
- PDF проверяется, дубли определяются по SHA-256; новый индекс публикуется только после успешного завершения. Предыдущие поколения сохраняются для восстановления.
- Проверено сохранение индекса Chroma, доступ к диалогам по владельцу, запрет загрузки работнику, блокировка после неверных паролей, первичная настройка администратора и UI-сценарии.
- Исправлены реальные ошибки: корректные цитаты без inline-номеров, несколько цитат из одного фрагмента, частично отсутствующие номера ссылок. Неизвестные номера и несуществующие цитаты по-прежнему отклоняются.
- Сквозная проверка настоящих моделей на изолированном синтетическом PDF прошла: быстрый ответ со сроком 12 рабочих дней; подробный ответ с этапами и сроками 12/3 дня и 5 лет; отказ на вопрос о температуре Марса.
- Последняя отдельная проверка краткого ответа подтверждает русский язык даже при английском PDF: «Отчёт должен быть подан в течение 12 рабочих дней после проверки [1]».
- pip check: конфликтов зависимостей нет; compileall: ошибок нет.
- Финальный полный прогон: 34 теста и 16 подслучаев прошли за 53,12 секунды. Заключительная проверка кода подтвердила устранение замечаний по ссылкам и запуску.
- Итоговая проверка цитирования: 5 тестов и 6 подслучаев прошли после последнего исправления.

## Эксплуатация и границы MVP

- Запуск Windows: start.cmd. Детали, установка на другую машину и offline-подготовка — README.md.
- На GTX 1050 Ti обнаружен сбой инициализации CUDA у Ollama; приложение и launcher используют CPU по умолчанию, YASTREB_NUM_GPU позволяет настроить другое оборудование.
- Измеренное время тестовых ответов на этом компьютере: примерно 23–73 секунды; отказ по нерелевантному контексту — 0,3 секунды. Время зависит от длины вопроса, прогрева и нагрузки.
- Сетевые API генерации/эмбеддингов не используются; полное испытание с физически отключённой сетью ещё не выполнялось.
- Вход локальный по корпоративной почте и паролю. SSO/AD, TLS для корпоративной сети и OCR не реализованы; эти отдельные инфраструктурные этапы требуют настроек организации.
- Общая библиотека видна всем вошедшим пользователям. ACL чтения по отделениям не входят в этот MVP.
- История сохраняется, но каждый вопрос ищет контекст самостоятельно. Проверка цитат не гарантирует безошибочность всех выводов LLM.
